Project: Agentic AI for Kubernetes Operations on NRP  
Organization: UC OSPO / San Diego Supercomputer Center  
Summary: This project delivers a modular, open-source Python framework that
integrates Kubernetes operations with LLM-powered explanations for the NRP
environment. Originally focused on anomaly detection for Seam, it evolved into
an Intelligent Kubernetes Management and Observability System inspired by the
INFOGENT design. The system routes user input between Kubernetes commands and
documentation queries, providing both direct execution and AI-driven guidance
to enhance usability, resilience, and research productivity.

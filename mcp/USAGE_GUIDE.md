## 🔧 Troubleshooting

### If Enhanced Responses Aren't Working:

1. **Check Server Status**:
   ```bash
   netstat -ano | findstr :8024
   ```

2. **Restart Enhanced Server**:
   ```bash
   # Kill existing servers
   # Start enhanced server
   python ultimate_fastmcp_server.py
   ```

3. **Verify GLM-V Configuration**:
   - Check `.env` file has correct NRP_API_KEY and NRP_BASE_URL
   - Ensure GLM-V model is accessible
